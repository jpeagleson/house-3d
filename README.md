# Our house in 3D

An interactive 3D model of our house and yard, viewable in any browser:
**https://jpeagleson.github.io/house-3d/**

Drag to orbit, right-drag to pan, scroll to zoom. Buttons switch between preset views; the slider moves the sun.

Built from public LiDAR elevation data, aerial photos and the assessor's building sketch, rendered with three.js.
Everything is in the single `index.html`.
